# Idle Country: image prompt pack

Use any image generator (ChatGPT, Gemini, Midjourney). Save each result as PNG with the **exact file name** below and put
them all in one folder (for example `Desktop\roblox\IdleCountryArt`). Tell me when some are ready: I crop, resize,
upload and wire them, replacing my drawn versions one by one. You don't need to do all of them at once.

## 1. Style block (paste this first, every time)

> Stylized 2D game illustration for a Roblox idle strategy game. Painterly digital art with clean ink outlines, soft
> cel shading, warm rim light, rich but slightly muted colors, subtle paper grain. Mood: grand, a little gritty,
> like a historical strategy board game. Same look as a polished mobile tycoon game. No text, no letters, no logos,
> no watermark, no UI, no border.

For anything marked **transparent**, add: *"isolated on a plain flat white background, centered, nothing else in the
picture"* (I remove the white). For **wide** scenes ask for the exact aspect ratio.
